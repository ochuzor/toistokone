# Inessiivi

## Quick guide

The Finnish inessive usually answers **missä?** — “where?” It often means “in” or “inside.” Many inessive forms end in **-ssa** or **-ssä**.

## More detail

Use the inessive for a location within something: *laukku* becomes *laukussa* — “in the bag.” It is also used for towns and countries, as in *Helsingissä* — “in Helsinki.”

The ending changes with the word and vowel harmony, so learn each common form together with the question **missä?**.
